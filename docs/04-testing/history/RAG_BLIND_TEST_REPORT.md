# RAG 盲测执行记录

> 历史记录：本文保留当时的语料、实现和执行结果，不代表当前系统状态。当前结论见 [第一阶段验收](../RAG_PHASE_ONE_ACCEPTANCE.md)，历史导航见 [历史索引](README.md)。


日期：2026-09-09  
范围：无预设过滤的公开检索、版本夹具、错误 metadata 与组织 A/B 隔离。  
生成模型：未调用 DeepSeek，也没有生成客服回答。

## 1. 过程

1. 使用 `advanced_rag_blind.jsonl` 中不需要夹具的 41 条公开问题，按 `k=6` 直接运行真实 `rag_service.search`，没有传入 metadata filter；
2. 导入 12 份短测试夹具：5 份历史/当前版本、1 份恶意指令样本、5 份 A/B 私有文档、1 份公共安全文档；
3. 导入时创建了仅用于本次测试的 `rag_eval_fixture_owner`、`rag_eval_org_a`、`rag_eval_org_b` 三个账户及 `rag-eval-org-a`、`rag-eval-org-b` 两个组织；
4. 运行 19 项专用检查：版本隔离、矛盾 metadata 为空结果、A/B 私有文档不泄露、公共文档对两个组织可见；
5. 发现三条初始断言将“不能看到对方文件”错误写成了“结果必须完全为空”。实际检索只返回了调用方自己的私有文档或公共文档，未返回对方文件；断言已修正为检查对方文件名绝不出现，并基于保存的同一批返回结果重新判定，未重复发起查询。

## 2. Qwen Embedding 调用范围

| 用途 | 次数 | 说明 |
|---|---:|---|
| 公共盲测查询 | 41 | 每条问题一次查询向量 |
| 测试夹具入库 | 12 | 每份短 Markdown 一次文档向量 |
| 夹具检查查询 | 19 | 每项检查一次查询向量 |
| 合计 | 72 | 均为 `text-embedding-v4`、256 维；无自动重试 |

服务端日志均返回向量维度 256；本记录不推断供应商实际计费 Token。没有 DeepSeek、没有流式答案、没有 LLM query rewrite 调用。

## 3. 公开盲测结果

公开集共 41 条，未传 category、channel、plan 等目标过滤：

| Top-K | 查询数 | Hit Rate@6 | Recall@6 | MRR | nDCG |
|---:|---:|---:|---:|---:|---:|
| 6 | 41 | 1.000 | 1.000 | 0.795 | 0.847 |

解释：目标文件都进入了 Top-6，但并非总在 Top-1；这与先前过滤烟雾集的 1.000 MRR/nDCG 不同，是更可信的排序基线。该结果仍只覆盖公开 Demo 语料，不能外推为生产知识库成绩。

## 4. 隔离夹具结果

| 专项 | 检查数 | 结果 | 验证事实 |
|---|---:|---|---|
| 版本/恶意文本 | 6 | 6/6 | 版本 filter 能区分 2025 与 2026；恶意文档可被当作数据检索，尚未执行模型服从性测试 |
| 错误 metadata | 6 | 6/6 | region、plan、channel、category、version 冲突时为零结果；组织 B 文档不会因 metadata 查询向组织 A 泄露 |
| A/B 组织隔离 | 7 | 7/7 | A/B 各自命中自己的私有文档，交叉查询未出现对方文件名；公共安全文档对二者均可见 |
| 合计 | 19 | **19/19** | 未发现跨组织检索泄露 |

## 5. 尚未通过本轮证明的能力

1. 恶意文档、无答案和个人状态问题的**最终 LLM 答复**是否安全：本轮只测检索，不调用 DeepSeek；
2. 两轮实体追问的真实 query rewrite：需在单独预算下做一次受限的 WebSocket E2E；
3. 并发 1/3/5、P50/P95、错误率和资源占用；
4. 更大规模、真实企业语料上的版本冲突与组织隔离。

## 6. 测试数据边界

测试账户、组织、存储对象及文件均带 `rag_eval_*` 或 `fixture-*` 前缀，和已有用户/公开 Demo 文档分离。它们目前保留，便于复跑；删除前应确认不再需要复现本报告。
