# 项目维护与技术债务

核对日期为 2026-11-19。本轮五项台账债务均已实现并补回归，源码与验收结果见[候选验收](archive/reports/RELEASE_CANDIDATE_ACCEPTANCE_2026-11-19.md)。源码版本可以封盘，目标环境构建、配置和放量仍按[发布手册](RELEASING.md)签验。

## 本轮关闭的五项债务

| 原优先级 | 关闭结果 | 验证与入口 |
| --- | --- | --- |
| P2 | 跨副本实时事件 | Redis Streams 传输已检查正文和事件，跨进程取消；增量携带完整正文，重放不重复追加。流有长度与两小时 TTL，Redis 故障时使用 SQL 快照恢复。[运行时](../backend/app/agent/generation.py) · [跨进程回归](../backend/tests/e2e/test_shared_generation_events.py) |
| P2 | 跨主机审批与自动恢复 | LangGraph 检查点移至应用 SQL，原决定为恢复权威；持久化任务按数据库时钟与租约领取，失效执行者受前后栅栏保护，启动回补旧决定，失败退避与回执核对，12 次后暂停并在审批台提示人工核查。管理员可保留原决定恢复。[实现](../backend/app/support/approval_execution.py) |
| P2 | Provider 未知消耗 | 出站前保存请求尝试、所有者、指纹和客户端关联 ID；用量回执持久化，未知值为 NULL，失去执行者的请求转 UNKNOWN。管理员输入供应商账单证据后逐笔校验、幂等对账，同一收据不能重复分配，保留前后值与操作人。[请求台账](../backend/app/accounting/provider_ledger.py) · [运维入口](OPERATIONS.md#provider-usage) |
| P3 | 全量 ESLint 门禁 | 补齐两个直接插件依赖，清理规则错误与警告，修复 Axios 请求 ID 遮蔽及 finally 吞异常；只读 lint 要求零警告，并与类型、构建和流式重放测试一起进入 CI。串行 PDF 操作保留附说明的逐行规则例外。[门禁](TESTING.md#ci) |
| P3 | 工单状态、审计与客服角色 | 限制状态迁移，终态不可改，处理结论必填并检查旧状态；每次修改同事务保存操作人与前后值，审批关单也有审计。新增 SUPPORT 角色，只能操作工单，不能审批、对账或管理用户。角色授予由管理员执行，记录审计并撤销旧 Token。[状态与审计](../backend/app/support/handoff.py) |

[债务专项回归](../backend/tests/e2e/test_debt_closure.py)覆盖 SQLite 与真实 MySQL，包括中断接管、重试暂停、收据去重与最小权限。旧 SQLite 检查点文件不再参与新执行；既有申请根据 SQL 原决定重建流程。历史处理动作无法倒推，审计从升级后的实际动作开始记录。

## 已关闭的前序问题

多标签页串会话、多副本重启与结算、审批中断换人恢复及邀请码退役均已有回归。地域与计费范围问题同四题真实复验 4/4 通过，原始回答和哈希见[前后证据](archive/evidence/N12_SCOPE_FAILURE_2026-10-20.md)。本轮另用相同四题验证实际 Provider 请求台账与用量回执一致。

## 发布验收与后续功能

| 范围 | 处理方式 |
| --- | --- |
| 目标环境发布 | 构建本次提交对应镜像，验证迁移、备份恢复、密钥及依赖配置、通知接手、性能阈值和回滚，再完成放量签验；源码 CI 不代替目标环境签验 |
| 真实退款渠道 | 仍使用合成支付沙箱；真实渠道、金额资格、回调验签及资金对账属于独立功能接入，不能将 SANDBOX_REFUNDED 解释为真实资金退款 |
| 供应商账单输入 | 网络超时无法凭本地信息推导真实消耗，UNKNOWN 需供应商账单或导出明细作为证据。对账入口不直接修改用户 Token 余额，额度结算继续执行生成终态事务规则 |
| 问答与检索扩展 | 普通自然语言矛盾的自动识别、扫描 OCR、截图理解及更大规模负载按明确需求独立验收 |
| 评测扩展 | 继续收集真实用户问法、独立盲审和目标流量性能基线，现有成绩适用对应语料、版本及样本条件 |
