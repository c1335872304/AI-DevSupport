## 性能与费用边界

- 基线真实查询 1,872 Tokens；跨格式真实编码/查询 98 Tokens；HTTP/UI 用量按每次验收进程报告记录在 `e2e-usage*.json`。业务表中的 Provider 请求号可用于核对；测试替身用量不是实际账单。
- 12 条冻结向量顺序查询的开发检查点：P50 约 492 → 602ms，P95 约 1,797 → 2,250ms；增加授权/版本检查有开销。本机同时存在开发和测试负载，样本不是压测，也不作为最终服务 SLO。后续性能优化归第四阶段，不宣称本轮加速。
- 有效文档的解析子进程冷启动约 15～36 秒，最高约 1.03 GiB RSS；后续可依据测量改为有边界的常驻解析服务，目前保留子进程隔离。

## 已知边界与部署状态

- 支持文字型 PDF 和 DOCX；扫描 OCR、旧 DOC、任意图表理解不属于首期。8 份样本不能证明任意复杂文档无损。
- 显式规则注解可检测同适用范围的值冲突；普通自然语言矛盾仍需证据核对。未把冲突提示冒充事实裁决。
- 恢复优先正确性，接管可重新计算部分内容；外部未知消耗需对账。物理 GC 和墓碑清扫允许延后，解析缓存可跨构建保留至文档删除。
- 原有 Docker Demo 未重建、未重启；新代码在专用 18016 API / 19527 前端及独立依赖环境验收。其他部署按运行说明先迁移和隔离旧 Worker，再部署；现有 Docker 镜像不自动包含独立 Docling 环境。
- 源目录没有 Git 仓库，交付使用源码 zip 和 SHA256 清单，不虚构 commit。源配置 `.env` 不写入归档。
