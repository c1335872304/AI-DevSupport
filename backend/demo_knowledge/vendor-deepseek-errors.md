# DeepSeek API：401、402、429 错误区分

厂商：DeepSeek。适用产品：DeepSeek 官方 API 错误码说明。
整理核对日期：2026-10-19。本文为官方资料的中文摘要，非完整镜像；该日期是核对时间。
官方来源：[Error Codes](https://api-docs.deepseek.com/quick_start/error_codes/)。

## 认证、余额与限流

DeepSeek 的 401 对应认证失败，应检查 Key；402 对应余额不足，应检查账户余额与充值情况；429 对应请求速率、并发或 QPS 限制，需要调整请求节奏并参考限速说明。

## 参数与服务故障

400 涉及请求格式，422 涉及参数。500 属于服务端故障，503 表示服务繁忙；后两类可等待后再尝试，持续异常需进一步排查。
