# 限流与 429 处理指南

HTTP 429 表示请求速率超过当前允许范围。需要区分“瞬时 QPS 超限”和“月度调用额度”，二者不是同一个概念。

## 1. 瞬时 QPS

QPS 表示每秒允许的请求数量。Demo 环境中的 Professional 套餐示例上限为 50 QPS。短时间突发到 80 QPS，即使当月总调用量还没有超额，也可能立即收到 429。

遇到 429 时，客服应优先：

- 通过 `query_recent_call_stats` 查看目标应用和 endpoint 的近期峰值 QPS 与 429 次数；
- 通过 `query_plan` 核对当前套餐的 QPS 限制；
- 使用 `query_error_code` 确认错误码是否为 `RATE_LIMIT_EXCEEDED`；
- 建议客户端采用指数退避、抖动（jitter）和合理并发控制。

## 2. 月度额度

月度额度用于计费或套餐用量统计，不直接等价于瞬时限流。例如 Demo Professional 套餐月额度为 1,000,000 次，但请求仍需要同时满足 QPS 限制。

## 3. 不应做的事情

- 不要在没有查询套餐和近期调用统计时直接断言“套餐太低”。
- 不要建议无限重试 429。
- 不要承诺自动提高限额或修改套餐；套餐变更属于业务操作，必要时应转人工。
