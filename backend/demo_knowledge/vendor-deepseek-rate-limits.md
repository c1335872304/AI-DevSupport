# DeepSeek API：并发限速与业务用户隔离

厂商：DeepSeek。适用产品：DeepSeek 官方 API 限速说明。
整理核对日期：2026-10-19。本文为中文摘要；具体模型与账号上限应查看官方当前文档，不在本快照中固定数值。
官方来源：[限速与隔离](https://api-docs.deepseek.com/zh-cn/quick_start/rate_limit/)。

## 并发与 Key 的关系

当前文档以请求发出至模型响应完成的区间计算并发；账号粒度的限制不会因为同账号换一把 API Key 就自然增加。超过适用并发上限可能收到 429。并发数量与每秒请求数不是同一指标。

## 业务用户标识

官方支持通过 `user_id` 区分业务侧用户，用于相关隔离与调度。该字段不应包含隐私信息；不同兼容协议的传递方式需按官方示例设置。用户隔离不表示绕过账号总并发限制，也不等于本地知识库 ACL。

## Demo 使用边界

以下为本项目约定：诊断需收集发生时并发、请求持续时间和脱敏响应，不能仅凭调用总数推算峰值并发；不承诺更换 Key 即可解除限流。本文不证明客户现有配额或具体模型上限，升级与扩容需要真实账户依据。
