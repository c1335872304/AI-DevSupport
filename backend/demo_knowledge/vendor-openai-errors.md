厂商：OpenAI。适用产品：OpenAI API 官方直连；其他网关可能改变响应。
整理核对日期：2026-10-19。内容为中文摘要，非官方全文镜像；快照日期不等于规则生效日期。
官方来源：[Error codes](https://developers.openai.com/api/docs/guides/error-codes)。

## 401 认证排查

401 可能涉及凭据不正确、组织成员关系或 IP 允许名单等条件。应结合具体错误消息和实际配置判断，不能仅凭状态码认定 Key 过期。

## 429 必须区分原因

OpenAI 的 429 不只表示请求过快，也可能对应余额、组织/项目支出上限或组织用量上限。检查错误详情，尤其是 `error.code`，再决定降速重试还是处理额度。`slow_down` 表示流量增长过快；费用或额度类限制不能靠持续重试恢复。

## 500 与 503

500 涉及服务端处理错误；503 可能是模型暂时过载。临时故障可以有限延迟重试；持续失败应保留请求号供排查。
