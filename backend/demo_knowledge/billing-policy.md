# 套餐、用量与账单说明

本文档用于解释 PaiSmart Demo 的计费结构。它可以回答“费用怎么算”，但不能证明“某个客户本月实际产生了多少费用”；个人真实账单必须通过 `query_plan`、`query_usage` 和 `query_bill` 查询。

## 1. Demo Professional 套餐

演示数据中的 Professional 套餐示例：

- 基础费用：299；
- 月度调用额度：1,000,000 次；
- QPS 上限：50；
- 超额调用单价：0.0005 / 次。

## 2. 超额费用计算

如果某月实际调用 1,250,000 次，则超过套餐额度 250,000 次。按 Demo 单价计算：

`250,000 × 0.0005 = 125`

因此示例账单为：

`299 基础费用 + 125 超额费用 = 424`

这只是演示计算规则。客服回答某个客户的账单时，应并行查询套餐、用量和账单 Tool，以真实返回值为准。

## 3. 争议账单与退款

客服 Agent 可以解释账单构成，但不能自行修改账单、降套餐、退差价或批准退款。客户对扣费有争议、要求退款或套餐变更时，应根据实际数据解释当前情况，并在需要写操作或人工审核时进入 `escalation` 流程。
